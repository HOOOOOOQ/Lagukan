## 🤝 Contributing to Lagukan Music Bot

1. [Fork the repository](https://github.com/HOOOOOOQ/Lagukan/fork)
2. Clone your fork: `git clone https://github.com/your-username/Lagukan.git`
3. Create your feature branch: `git checkout -b my-new-feature`
4. Stage changes `git add .`
5. Commit your changes: `git commit -m "feat: add my new feature"`
6. Push to the branch: `git push origin my-new-feature`
7. Submit a pull request
